Use it as an app

Add Mesh Owners to your home screen or computer. It opens full screen with its own icon, and you stay signed in.

  • iPhone or iPad: open this page in Safari, tap the Share button, then Add to Home Screen.
  • Android: in Chrome, tap the ⋮ menu, then Install app (or Add to Home screen).
  • Computer: in Chrome or Edge, click the install icon at the right of the address bar, or the Install app button at the top of this page.

On iPhone, the home screen app keeps its own saved quotes, separate from Safari. Use a backup file to move quotes from one to the other.

Backup and other devices

Your quotes and prices are saved in this browser, on this device only. Nothing is uploaded. To keep a copy, or to share with the other owner, save a backup file and import it on the other device. Importing combines it with what's already there, and the most recently edited version of each quote wins.
